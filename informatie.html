Informatie over de opleiding

Hier vindt je handige informatie om voorbereid te zijn voor de opleiding.

Vakken

Dit zijn vakken die je kunt verwachten op de opleiding:

  • Website (ontwikkelen)
  • Basis Programmeren
  • Basis ICT
  • DevOps
  • Nederlands
  • Engels
  • Rekenen
  • Burgerschap

Programmeer- en opmaaktalen

Op de opleiding leer je een aantal computertalen

  • Java
  • C++
  • JavaScript
  • PHP
  • HTML
  • CSS

Rooster & Stage

Je doet 4 leerjaren over de stage, elk leerjaar is verdeeld in 4 periodes. Het rooster veranderd per periode. In je eerste leerjaar ga je de basis leren als software developer. Hier krijg je ook keuzendelen.

In je 2e, 3e en 4e leerjaar ga je voor 20 weken op stage; dat houdt in dat je dus tijdelijk werken voor een bedrijf om een idee te krijgen hoe het daadwerkelijk is op de werkvloer als software developer. Je gaat ook doelen stellen voor jezelf om uit te voeren.

Toekomst

Nadat je de opleiding hebt afgerond, heb je als software developer veel keuze op de arbeidsmarkt.

Overal wordt software gebruikt en organisaties hebben daarom goede software developers nodig.

Daarnaast kan je altijd ook verder studeren, bijvoorbeeld een andere (ICT-)opleiding, of het HBO
